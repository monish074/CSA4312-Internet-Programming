# TechSavvy — Online Gadget Shopping System

Responsive multi-page online gadget store prototype.

## Pages
Home, product catalogue, product details, deals, cart, checkout, login, registration, wishlist, order history, order tracking, admin console and contact/support.

## Features
- Smartphones, laptops, tablets and accessories categories
- Product search, category filtering and price sorting
- Product details, add-to-cart, quantity editing and remove
- Wishlist, checkout demo, order history and tracking
- Admin can add/remove products, edit prices and descriptions, and view checkout records
- Browser localStorage stores demo data

## Run
Extract the ZIP and open `index.html` in a browser. No build tools required.

## Limitations
This is a front-end academic demonstration. It has no backend, real authentication, database, live inventory, real payment gateway, email/SMS notification or courier integration. Demo records remain in the current browser's localStorage. Do not enter real personal or payment information.
