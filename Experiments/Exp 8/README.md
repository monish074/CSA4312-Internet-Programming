# MedCare – Advanced Hospital Appointment Booking System

## Pages
Home, doctor search, hospital directory, doctors, appointment booking, pre-visit check-in, patient dashboard, appointment history, patient login/register, hospital registration/dashboard, admin console, reviews and contact.

## Run
Extract the ZIP, open this folder in VS Code and run `index.html` using Live Server.

## Features
- Search doctors by specialty and location
- Hospital directory with Google Maps search links for individual hospitals
- Doctor profiles with specialties, sample ratings and consultation fees
- Appointment booking with date/time selection and duplicate-slot check in the current browser
- Appointment cancellation, patient dashboard and history
- Pre-visit check-in form
- Patient registration/login demo
- Hospital registration and profile dashboard
- Admin appointment table, sample statistics and CSV export
- Patient feedback form
- Distinct page palettes: terracotta, olive, warm sand, plum, marigold, sage, burgundy and more

## Important
This is an academic front-end demo using HTML, CSS, JavaScript and browser localStorage. It does not provide real authentication, secure server/database storage, live doctor availability, actual email/SMS reminders, or healthcare-regulatory compliance. Do not enter real patient information. A production system needs secure backend APIs, role-based access, encryption, audit logs, consent workflows, protected medical records and a compliance review for the applicable country. Email/SMS reminders require a configured provider.
