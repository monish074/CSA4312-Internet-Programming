SUGARBLOOM ONLINE CAKE ORDERING SYSTEM
Run: Extract ZIP, open folder in VS Code, run index.html using Live Server.
Pages: index.html storefront, cart.html, checkout.html, track.html, admin.html.
Features: cake catalogue, category/search/sort, responsive UI, cart, quantity controls,
checkout form, simulated payment selection, generated order ID, order tracking,
admin product add/delete, order status updates, CSV export, localStorage persistence.
Technology: HTML5, CSS3, JavaScript ES6, browser LocalStorage.
Demo limitations: no real payment gateway, email/SMS, maps, live delivery API or server database.
LocalStorage is device/browser-specific and is not suitable for production personal data.
For production, implement backend authentication, database, HTTPS, validation, payment and email APIs.
